# @snake/game-engine

Core Snake gameplay logic: bootstrapping the game, the game loop, snake movement, food spawning, collision detection, input handling, and sounds.

**Nx project name:** `shared-game-engine`

## Commands

```bash
npx nx build shared-game-engine
npx nx test shared-game-engine
npx nx lint shared-game-engine
npx nx typecheck shared-game-engine
```
